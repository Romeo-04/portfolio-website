# Café Toon Look and Pour (Build Step 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the `/cafe` blockout its toon look (banded shading and ink
outlines) and make the four signature cups pour their tech-stack layers as
the visitor scrolls through the brew bar.

**Architecture:** One shared 3-band gradient texture drives every
`MeshToonMaterial`. drei's `<Outlines>` draws ink lines on each mesh, so
models need no hand-made outline geometry. The pour is a small
`ShaderMaterial` that colours a cylinder by height and discards everything
above a `uFill` uniform. All number logic (gradient bands, which cup pours
when, which layer a height belongs to) is pure and unit-tested. The scene
only wires it up.

**Tech Stack:** three 0.185, @react-three/fiber 9.8, @react-three/drei 10.7
(`Outlines`), vitest 3.

**Spec:** `docs/superpowers/specs/2026-10-11-coffee-shop-portfolio-design.md`
(build order step 2; section 3 "Toon look", units `materials/toon.ts` and
`shaders/pour.ts`).

**Scope:** Build step 2 only. Not in this plan: bloom and film grain (they
belong with station lighting in step 3), station animations (step 3), HUD
(step 4), Blender models (step 5). The 2D drink illustration already
shipped in step 1.

**One deliberate deviation from the spec:** spec section 3 says outlines
come "from a post-processing pass". This plan uses drei `<Outlines>`
(an inverted-hull outline added per mesh) instead. The spec's goal, "models
stay simple with no hand-made outline meshes", still holds: step 5 adds
`<Outlines>` to every mesh of a loaded model in code. Reasons: it needs no
extra dependency or normal/depth pass, it is per-object controllable, and it
stays cheap on phones. Cost if this is wrong: a later swap to a
post-processing edge pass touches only `components/cafe/scene.tsx`.

## Global Constraints

- `/` (Flow State) and the `/cafe` menu modes must keep working. Every task
  ends with `npm run build` green.
- `/cafe` stays `noindex, nofollow`.
- Toon shading uses exactly 3 bands: `TOON_BANDS = [0.45, 0.75, 1]`.
- Ink colour `#1b120c`, outline thickness `0.03` (world units).
- A drink's layers stack bottom to top in `drinkFor(project).layers` order,
  the same as the 2D illustration (layer 0 at the bottom). At most
  `MAX_LAYERS` (4) layers.
- Cups pour only while the camera rests at the brew bar (the first `DWELL`
  of the brew-bar slice), one after another, left to right.
- Reduced motion: pouring is scroll-driven, so it stays. No extra
  time-based animation is added.
- Commits follow `.claude/skills/git-operations/SKILL.md`. **No
  `Co-Authored-By` trailer or attribution footer.**
- Do not stage `lib/particle-shapes.ts` (the user's work in progress) or
  `.superpowers/`.
- Branch `feat/cafe-toon`. Merging to `main` needs the user's explicit yes.

## Review Focus

1. **Scrolling backwards** through the brew bar: cups must un-pour
   smoothly. Fill is a pure function of progress, so there is no stored
   state. Pinned in Task 2 (`cupFill` is symmetric in progress).
2. **A drink with 1 layer** (empty stack → "House blend") or 4 layers: the
   shader must colour the whole cup with valid layer indices (no index
   ≥ count). Pinned in Task 2 (`layerIndexAt`) and Task 3 (uniform
   padding).
3. **Fill exactly 0 and exactly 1:** at 0 the liquid is invisible (no
   sliver); at 1 the top layer fully shows. Pinned in Task 2 and in the
   shader's `>=` comparison in Task 3.
4. **WebGL1 devices:** the shader must compile without dynamic array
   indexing. Pinned in Task 3 by the loop-select pattern and a test that the
   fragment source contains no `uColors[idx]`.
5. **The menu-as-page modes** (phones, no WebGL) must not load the new
   three code. Pinned in Task 4: the new modules are imported only from
   `components/cafe/scene.tsx`, which is already a `next/dynamic` chunk.

// ============================================================
// TOON MATERIAL
// ============================================================
// Three hard light bands instead of smooth shading (spec section 3,
// "Toon look"). Every MeshToonMaterial in the café uses this one
// gradient texture, so the whole shop shares one lighting style.
// ============================================================

import { DataTexture, NearestFilter, RedFormat } from "three";

export const TOON_BANDS = [0.45, 0.75, 1] as const;

/** Ink colour for outlines: the café's darkest roast. */
export const INK = "#1b120c";

/** Outline width in world units. */
export const OUTLINE_THICKNESS = 0.03;

let gradient: DataTexture | null = null;

export function toonGradient(): DataTexture {
  if (gradient) return gradient;
  const data = new Uint8Array(TOON_BANDS.map((b) => Math.round(b * 255)));
  gradient = new DataTexture(data, TOON_BANDS.length, 1, RedFormat);
  gradient.minFilter = NearestFilter;
  gradient.magFilter = NearestFilter;
  gradient.needsUpdate = true;
  return gradient;
}
```

// ============================================================
// POUR MATH
// ============================================================
// Which cup is pouring, and how full, is a pure function of scroll
// progress: scrolling back un-pours with no stored state. Cups pour in
// turn while the camera rests at the brew bar (the dwell zone).
// layerIndexAt is the JavaScript twin of the pour shader's layer pick,
// kept here so the rule is tested.
// ============================================================

import { DWELL, stationProgress } from "@/lib/cafe/stations";

const clamp01 = (v: number) => Math.min(1, Math.max(0, v));

export function cupFill(progress: number, cupIndex: number, cupCount: number): number {
  if (cupCount <= 0) return 0;
  const dwell = clamp01(stationProgress(progress, "brew-bar") / DWELL);
  return clamp01(dwell * cupCount - cupIndex);
}

export function layerIndexAt(height: number, layerCount: number): number {
  const i = Math.floor(clamp01(height) * layerCount);
  return Math.min(Math.max(i, 0), layerCount - 1);
}
```

// ============================================================
// POUR SHADER
// ============================================================
// Colours a cylinder by height: each band is one layer of the drink, bottom
// to top (same order as the 2D illustration). Everything above uFill is
// discarded, so raising uFill "pours" the drink. Shading uses the same
// three-band idea as the toon material. The layer pick loops instead of
// indexing uColors[idx], which WebGL1 does not allow. three.Color stores
// linear values, so the colorspace chunk converts back to sRGB on output.
// ============================================================

import { Color, DoubleSide, ShaderMaterial } from "three";
import { MAX_LAYERS, type Drink } from "@/lib/cafe/drinks";

const vertexShader = /* glsl */ `
  uniform float uHeight;
  varying float vH;
  varying vec3 vNormal;
  void main() {
    vH = position.y / uHeight + 0.5;
    vNormal = normalize(normalMatrix * normal);
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

const fragmentShader = /* glsl */ `
  uniform float uFill;
  uniform vec3 uColors[${MAX_LAYERS}];
  uniform int uCount;
  varying float vH;
  varying vec3 vNormal;
  void main() {
    if (uFill <= 0.0 || vH >= uFill) discard;
    int pick = int(clamp(floor(vH * float(uCount)), 0.0, float(uCount - 1)));
    vec3 color = uColors[0];
    for (int i = 1; i < ${MAX_LAYERS}; i++) {
      if (i == pick) color = uColors[i];
    }
    float light = dot(normalize(vNormal), normalize(vec3(0.4, 0.8, 0.6)));
    float band = light > 0.5 ? 1.0 : (light > 0.0 ? 0.8 : 0.6);
    gl_FragColor = vec4(color * band, 1.0);
    #include <colorspace_fragment>
  }
`;

export function createPourMaterial(drink: Drink, height: number): ShaderMaterial {
  const colors = Array.from({ length: MAX_LAYERS }, (_, i) => {
    const layer = drink.layers[Math.min(i, drink.layers.length - 1)];
    return new Color(layer.color);
  });
  return new ShaderMaterial({
    vertexShader,
    fragmentShader,
    side: DoubleSide,
    uniforms: {
      uFill: { value: 0 },
      uHeight: { value: height },
      uColors: { value: colors },
      uCount: { value: drink.layers.length },
    },
  });
}

export function setFill(material: ShaderMaterial, fill: number): void {
  material.uniforms.uFill.value = Math.min(1, Math.max(0, fill));
}

"use client";

// ============================================================
// CAFÉ SCENE (toon blockout)
// ============================================================
// Build step 2: the placeholder stations get the toon look (three light
// bands and ink outlines), and the four signature cups pour their stack
// as the visitor scrolls through the brew bar. Step 5 swaps the boxes for
// Blender models; every model mesh gets the same toon material and
// <Outlines>.
// ============================================================

import { Html, Outlines } from "@react-three/drei";
import { Canvas, useFrame } from "@react-three/fiber";
import { useMemo } from "react";
import type { ShaderMaterial } from "three";
import { INK, OUTLINE_THICKNESS, toonGradient } from "@/components/cafe/materials/toon";
import { createPourMaterial, setFill } from "@/components/cafe/shaders/pour";
import { projectsData } from "@/data/portfolio";
import { drinkFor } from "@/lib/cafe/drinks";
import { cupFill } from "@/lib/cafe/pour";
import { getProgress } from "@/lib/cafe/scroll";
import { STATIONS, cameraPose } from "@/lib/cafe/stations";

const STATION_COLORS = ["#c0632f", "#3d5a40", "#8a5a3b", "#a8873c", "#5a3620", "#c8873a", "#7a4a2a"];

const CUP_HEIGHT = 0.4;

function Ink() {
  return <Outlines thickness={OUTLINE_THICKNESS} color={INK} />;
}

function CameraRig({ cut }: { cut: boolean }) {
  useFrame(({ camera }) => {
    const pose = cameraPose(getProgress(), { cut });
    camera.position.set(...pose.position);
    camera.lookAt(...pose.target);
  });
  return null;
}

function PouringCup({
  project,
  index,
  count,
}: {
  project: (typeof projectsData)[number];
  index: number;
  count: number;
}) {
  const liquid = useMemo<ShaderMaterial>(
    () => createPourMaterial(drinkFor(project), CUP_HEIGHT * 0.9),
    [project],
  );
  useFrame(() => setFill(liquid, cupFill(getProgress(), index, count)));

  return (
    <group position={[(index - (count - 1) / 2) * 0.6, CUP_HEIGHT / 2 + 0.15, 0.6]}>
      {/* Glass: a see-through toon shell with an ink rim. */}
      <mesh>
        <cylinderGeometry args={[0.18, 0.14, CUP_HEIGHT, 24, 1, true]} />
        <meshToonMaterial color="#f6ead8" gradientMap={toonGradient()} transparent opacity={0.25} />
        <Ink />
      </mesh>
      {/* Liquid: slightly smaller so it sits inside the glass. */}
      <mesh material={liquid}>
        <cylinderGeometry args={[0.165, 0.13, CUP_HEIGHT * 0.9, 24]} />
      </mesh>
    </group>
  );
}

function SignatureCups() {
  const brewBar = STATIONS.find((s) => s.id === "brew-bar");
  if (!brewBar) throw new Error("brew-bar station missing");
  const [x, y, z] = brewBar.camera.target;
  const signature = projectsData.filter((p) => p.featured);
  return (
    <group position={[x, y, z]}>
      {signature.map((p, i) => (
        <PouringCup key={p.slug} project={p} index={i} count={signature.length} />
      ))}
    </group>
  );
}

function PlaceholderShop() {
  return (
    <>
      <mesh rotation-x={-Math.PI / 2} position={[0, 0, 0]}>
        <planeGeometry args={[40, 40]} />
        <meshToonMaterial color="#3a2618" gradientMap={toonGradient()} />
      </mesh>
      {STATIONS.map((s, i) => (
        <group key={s.id} position={[...s.camera.target]}>
          <mesh>
            <boxGeometry args={[1.6, 1, 0.6]} />
            <meshToonMaterial color={STATION_COLORS[i]} gradientMap={toonGradient()} />
            <Ink />
          </mesh>
          <Html center position={[0, 0.9, 0]} className="font-chalk pointer-events-none text-2xl whitespace-nowrap text-[#f5e9da]">
            {s.label}
          </Html>
        </group>
      ))}
      <SignatureCups />
    </>
  );
}

export default function CafeScene({ cut }: { cut: boolean }) {
  return (
    <div aria-hidden className="fixed inset-0">
      <Canvas camera={{ fov: 50, position: [...STATIONS[0].camera.position] }} dpr={[1, 2]}>
        <color attach="background" args={["#1b120c"]} />
        <ambientLight intensity={0.5} />
        <directionalLight position={[5, 8, 5]} intensity={1.6} />
        <pointLight position={[0, 3, 0]} intensity={8} color="#ffb36b" />
        <CameraRig cut={cut} />
        <PlaceholderShop />
      </Canvas>
    </div>
  );
}
