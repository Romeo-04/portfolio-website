# Café HUD and Secret Drink (Build Step 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the game layer on top of the café: a loyalty card that stamps
each station the visitor reaches, an order rail of collected tickets that
jumps back to a station, and a secret "Off the Clock" drink that unlocks
when the card is full.

**Architecture:** Stamp rules are pure and tested in `lib/cafe/loyalty.ts`,
including storage parsing that never throws. A client `Hud` subscribes to
the scroll store, but changes React state only when the visitor reaches a
new station, never on every scroll event. The secret drink content lives in
`data/portfolio.ts` as `offTheClock`, so the user edits it like other
content.

**Tech Stack:** React 19, Tailwind v4, vitest 3. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-11-coffee-shop-portfolio-design.md`
(section 4 "HUD", section 2.3 "Secret drink", build step 4).

**Base branch:** `feat/cafe-stations-b`. Branch `feat/cafe-hud` from it.

**Content note:** the spec says the user writes the "Off the Clock" content
(hobbies, real coffee order, fun fact) before this step. It has not been
provided. This plan ships `offTheClock = null` and a graceful card ("The
barista is still writing this one — check back soon."). The user fills it
in later with no code change. The PR body asks for the content.

## Global Constraints

- 7 stamps, one per station in `STATIONS`, in journey order. Saved in
  `localStorage` key `cafe-stamps` as a JSON array of station ids.
- A station is stamped once the visitor's progress enters that station's
  slice (`stationIndexAt(progress)`).
- Storage may be blocked or hold garbage: parsing never throws and drops
  unknown ids and duplicates.
- The HUD updates state only when the current station changes.
- Order rail tickets are buttons in journey order. Clicking one calls
  `goTo(id, { immediate: reduced })`.
- The secret drink panel is a labelled dialog (`role="dialog"`,
  `aria-modal="true"`, `aria-labelledby`). It takes focus on open, closes
  on Escape and with its close button, and returns focus to the loyalty
  card button.
- Phones (light 3D): the order rail is hidden below the `sm` breakpoint;
  the loyalty card stays.
- `/` and the menu modes are untouched. `npm run build` green after each
  task.
- Commits follow `.claude/skills/git-operations/SKILL.md`. **No
  `Co-Authored-By` trailer or attribution footer.** Do not stage
  `lib/particle-shapes.ts` or `.superpowers/`.

## Review Focus

1. **Corrupt storage** (`"[1,2"`, `"{}"`, `["storefront","nope"]`): no
   crash, and only valid ids are kept. Pinned in Task 1.
2. **Deep link to the checkout:** visiting only some stations must not
   fill the card. Stamps come from stations actually reached, not from
   jumps over them. Pinned in Task 1 (`addStamp` adds one id) and Task 2
   (stamps the station the visitor lands on, not the ones skipped).
3. **Re-renders:** scrolling inside one station must not re-render the
   HUD. Pinned in Task 2 by keeping the last station in a ref.
4. **Secret drink focus handling:** focus moves in, Escape closes it, and
   focus returns to the card. Pinned in Task 2.
5. **`offTheClock` null:** the unlocked card shows the graceful message.
   Pinned in Task 2.

import { describe, expect, it } from "vitest";
import type { StorageLike } from "@/lib/cafe/intro";
import {
  STAMPS_KEY,
  addStamp,
  isComplete,
  loadStamps,
  parseStamps,
  saveStamps,
} from "@/lib/cafe/loyalty";
import { STATIONS } from "@/lib/cafe/stations";

describe("parseStamps", () => {
  it("keeps valid ids in journey order without duplicates", () => {
    expect(parseStamps('["wall","storefront","wall"]')).toEqual(["storefront", "wall"]);
  });
  it("survives garbage", () => {
    expect(parseStamps(null)).toEqual([]);
    expect(parseStamps("[1,2")).toEqual([]);
    expect(parseStamps("{}")).toEqual([]);
    expect(parseStamps('["storefront","nope",3]')).toEqual(["storefront"]);
  });
});

describe("addStamp", () => {
  it("adds one station in journey order", () => {
    expect(addStamp(["wall"], "storefront")).toEqual(["storefront", "wall"]);
  });
  it("returns the same array when already stamped", () => {
    const s = ["wall" as const];
    expect(addStamp(s, "wall")).toBe(s);
  });
});

describe("isComplete", () => {
  it("is true only with every station", () => {
    expect(isComplete(STATIONS.map((s) => s.id))).toBe(true);
    expect(isComplete(STATIONS.slice(1).map((s) => s.id))).toBe(false);
  });
});

describe("load and save", () => {
  const memory = (): StorageLike & { data: Record<string, string> } => {
    const data: Record<string, string> = {};
    return { data, getItem: (k) => data[k] ?? null, setItem: (k, v) => void (data[k] = v) };
  };
  const broken: StorageLike = {
    getItem: () => {
      throw new Error("blocked");
    },
    setItem: () => {
      throw new Error("blocked");
    },
  };

  it("round-trips", () => {
    const s = memory();
    saveStamps(s, ["storefront", "wall"]);
    expect(s.data[STAMPS_KEY]).toBe('["storefront","wall"]');
    expect(loadStamps(s)).toEqual(["storefront", "wall"]);
  });
  it("never throws on blocked or missing storage", () => {
    expect(loadStamps(broken)).toEqual([]);
    expect(loadStamps(null)).toEqual([]);
    expect(() => saveStamps(broken, ["wall"])).not.toThrow();
  });
});

```ts
// ============================================================
// LOYALTY CARD
// ============================================================
// One stamp per station the visitor reaches (spec section 4). Stamps are
// kept in journey order and saved in localStorage; storage can be blocked
// or hold garbage, so nothing here throws.
// ============================================================

import type { StorageLike } from "@/lib/cafe/intro";
import { STATIONS, type StationId } from "@/lib/cafe/stations";

export const STAMPS_KEY = "cafe-stamps";

const ORDER = STATIONS.map((s) => s.id);

function inJourneyOrder(ids: Iterable<StationId>): StationId[] {
  const set = new Set(ids);
  return ORDER.filter((id) => set.has(id));
}

export function parseStamps(raw: string | null): StationId[] {
  if (!raw) return [];
  try {
    const value: unknown = JSON.parse(raw);
    if (!Array.isArray(value)) return [];
    return inJourneyOrder(value.filter((v): v is StationId => ORDER.includes(v as StationId)));
  } catch {
    return [];
  }
}

export function addStamp(stamps: StationId[], id: StationId): StationId[] {
  if (stamps.includes(id)) return stamps;
  return inJourneyOrder([...stamps, id]);
}

export function isComplete(stamps: StationId[]): boolean {
  return ORDER.every((id) => stamps.includes(id));
}

export function loadStamps(storage: StorageLike | null): StationId[] {
  try {
    return parseStamps(storage?.getItem(STAMPS_KEY) ?? null);
  } catch {
    return [];
  }
}

export function saveStamps(storage: StorageLike | null, stamps: StationId[]): void {
  try {
    storage?.setItem(STAMPS_KEY, JSON.stringify(stamps));
  } catch {
    // Blocked storage: the card resets next visit, nothing else breaks.
  }
}
```

- [ ] **Step 2: Create `components/cafe/hud.tsx`**

```tsx
"use client";

// ============================================================
// HUD
// ============================================================
// The game layer over the café (spec section 4): a loyalty card that stamps
// each station the visitor reaches, an order rail to jump back, and the
// secret "Off the Clock" drink once the card is full. It listens to the
// scroll store but only re-renders when the current station changes.
// ============================================================

import { useEffect, useId, useRef, useState } from "react";
import { offTheClock } from "@/data/portfolio";
import { addStamp, isComplete, loadStamps, saveStamps } from "@/lib/cafe/loyalty";
import { getProgress, goTo, subscribeProgress } from "@/lib/cafe/scroll";
import { STATIONS, stationIndexAt, type StationId } from "@/lib/cafe/stations";

function storage(): Storage | null {
  try {
    return window.localStorage;
  } catch {
    return null;
  }
}

export default function Hud({ reduced }: { reduced: boolean }) {
  const [stamps, setStamps] = useState<StationId[]>(() => loadStamps(storage()));
  const [secretOpen, setSecretOpen] = useState(false);
  const last = useRef<StationId | null>(null);
  const cardRef = useRef<HTMLButtonElement>(null);
  const panelRef = useRef<HTMLDivElement>(null);
  const titleId = useId();

  useEffect(() => {
    const onScroll = () => {
      const id = STATIONS[stationIndexAt(getProgress())].id;
      if (id === last.current) return;
      last.current = id;
      setStamps((prev) => {
        const next = addStamp(prev, id);
        if (next !== prev) saveStamps(storage(), next);
        return next;
      });
    };
    onScroll();
    return subscribeProgress(onScroll);
  }, []);

  useEffect(() => {
    if (!secretOpen) return;
    panelRef.current?.focus();
    const onKey = (e: KeyboardEvent) => {
      if (e.key === "Escape") setSecretOpen(false);
    };
    window.addEventListener("keydown", onKey);
    return () => {
      window.removeEventListener("keydown", onKey);
      cardRef.current?.focus();
    };
  }, [secretOpen]);

  const complete = isComplete(stamps);

  return (
    <>
      <button
        ref={cardRef}
        type="button"
        onClick={() => complete && setSecretOpen(true)}
        aria-label={
          complete
            ? "Loyalty card full: open your secret drink"
            : `Loyalty card: ${stamps.length} of ${STATIONS.length} stamps`
        }
        aria-disabled={!complete}
        className="font-receipt fixed top-4 left-4 z-20 rounded-sm bg-[#f6ead8] px-3 py-2 text-[#2b1a10] shadow-lg"
      >
        <span className="block text-[10px] tracking-[0.2em]">LOYALTY CARD</span>
        <span aria-hidden className="mt-1 flex gap-1">
          {STATIONS.map((s) => (
            <span
              key={s.id}
              className={`grid h-5 w-5 place-items-center rounded-full border border-[#2b1a10]/40 text-[10px] ${stamps.includes(s.id) ? "bg-[#c0632f] text-[#f6ead8]" : ""}`}
            >
              {stamps.includes(s.id) ? "☕" : ""}
            </span>
          ))}
        </span>
      </button>

      <nav aria-label="Visited stations" className="fixed top-4 left-1/2 z-20 hidden -translate-x-1/2 gap-2 sm:flex">
        {stamps.map((id) => {
          const station = STATIONS.find((s) => s.id === id);
          return (
            <button
              key={id}
              type="button"
              onClick={() => goTo(id, { immediate: reduced })}
              className="font-receipt rounded-sm bg-[#f6ead8]/90 px-2 py-1 text-[11px] text-[#2b1a10] shadow"
            >
              {station?.label}
            </button>
          );
        })}
      </nav>

      {secretOpen && (
        <div className="fixed inset-0 z-40 grid place-items-center bg-[#1b120c]/70 p-4">
          <div
            ref={panelRef}
            role="dialog"
            aria-modal="true"
            aria-labelledby={titleId}
            tabIndex={-1}
            className="w-full max-w-sm rounded-md bg-[#f6ead8] p-6 text-[#2b1a10] shadow-2xl"
          >
            <h2 id={titleId} className="font-chalk text-3xl">
              Off the Clock
            </h2>
            {offTheClock ? (
              <div className="mt-3 space-y-2 text-sm">
                <p>
                  <strong>My order:</strong> {offTheClock.coffeeOrder}
                </p>
                <p>
                  <strong>Off the clock:</strong> {offTheClock.hobbies.join(" · ")}
                </p>
                <p>
                  <strong>Fun fact:</strong> {offTheClock.funFact}
                </p>
              </div>
            ) : (
              <p className="mt-3 text-sm">The barista is still writing this one — check back soon.</p>
            )}
            <button
              type="button"
              onClick={() => setSecretOpen(false)}
              className="font-receipt mt-5 rounded-sm border border-[#2b1a10]/40 px-4 py-2 text-sm"
            >
              Close
            </button>
          </div>
        </div>
      )}
    </>
  );
}
```
